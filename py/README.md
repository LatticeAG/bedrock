# latticeagi-bedrock (Python)

Python core of Bedrock: versioned signed charters, exact version pins,
gateway allow/deny evaluation, advisory disputes, offline audit/evidence
verification, and a `python -m bedrock` CLI that is byte-identical to the
TypeScript `@latticeagi/bedrock` implementation on the shared conformance
corpus (`conformance/vectors.jsonl`, TV-B--01..55).

See the repository root `README.md` for the full documentation, quick start,
and the hosted-surface boundary. License: MIT.

```bash
pip install latticeagi-bedrock
python -m bedrock --help
```
